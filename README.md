# PIT II — Cupcakes Gourmet | Wesley Sousa Machado

Projeto acadêmico de **Wesley Sousa Machado — RGM 37181921**, desenvolvido como continuidade da PIT I.

## Contexto
Na PIT I foi trabalhado o desenvolvimento de uma solução para uma loja de cupcakes gourmet, considerando necessidades relacionadas a:
- vendas online;
- pedidos;
- pagamentos;
- entregas;
- organização do fluxo de compra;
- melhoria da experiência do usuário;
- apoio à gestão da loja virtual.

## Base utilizada na PIT I
Foram considerados:
- requisitos ágeis;
- histórias de usuário;
- backlog de produto;
- casos de uso;
- UML;
- wireframes;
- experiência do usuário;
- requisitos funcionais e não funcionais;
- metodologias ágeis para organização e planejamento.

## Objetivo
Dar continuidade ao planejamento da PIT I e transformar requisitos, histórias de usuário, backlog, modelagem e protótipos em uma solução funcional e testável.

## PIT II
Nesta etapa, será implementada uma aplicação web responsiva representando o fluxo principal de compra de cupcakes, incluindo catálogo, carrinho, pedido, pagamento, entrega e acompanhamento do pedido.
